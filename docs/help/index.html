pgtc — Postgres terminal commander

A PostgreSQL administration and query tool that runs entirely in the terminal — locally or over SSH, on Linux, Windows and macOS. It looks and is used like Midnight Commander and works like pgAdmin.

What you can do with pgtc

Browse a serverDatabases, schemas, relations, columns, indexes, functions, triggers, roles, tablespaces — read from the system catalogs; find any object by name. Read definitionsThe DDL of the selected object, reconstructed from the catalogs, as in pgAdmin's SQL tab. Run SQLQuery tabs, each with its own session: streamed result sets, messages, cancel, transaction control and PL/pgSQL mode. Edit comfortablyA fast editor with highlighting, find / replace, undo and autocomplete from the live database. Work with filesOpen and save SQL files; export any result to CSV, JSON or XML. Use psql's commandsdt, d table, df… and commands that generate SELECT, INSERT, UPDATE, MERGE, triggers and views for a table. Generate SQL from templatesFill in a short form, get ready-to-run CREATE and DROP statements. Add your own templates. Make your own templatesThe template editor: parameters from dialogs, helpers for the body, a live preview, a test in the real form. Ask AI for SQLDescribe what you need in your words; a model that knows your database structure writes the SQL into the editor. Nothing runs by itself. Synchronise a schemaExport a database's schema definition to a .pgdef file and generate the DDL that brings another database to it. Watch a serverLive graphs, sessions, blocking, progress of VACUUM and CREATE INDEX, locks; cancel or terminate sessions. Profile SQLEvery statement the server runs, with duration, parameters and errors. Read statisticsSize, cache hit ratio, transactions, tuples and more for one database, from the cumulative statistics views. Make it yoursSettings, six colour schemes (or your own), every key changeable.

About the examples

The examples and screenshots use AdventureWorks, the well-known sample database of a bicycle manufacturer, in its PostgreSQL form: a database adventureworks with the schemas humanresources, person, production, purchasing and sales. Most examples use the tables sales.customer, sales.salesorderheader, sales.salesterritory and person.person. The screenshots show a server saved as local and a second one, production.

The pictures are drawn by pgtc's own screen renderer in the default colour scheme Classic on a 120 × 34 terminal; the data in them is sample data.

Supported servers and terminals

  • PostgreSQL 11 and newer. pgtc reads server_version_num after connecting and refuses an older server. Major versions up to 18 are verified; a newer one connects with the warning “PostgreSQL N – not yet verified with pgtc” and is handled with the catalog queries of the newest known version.
  • Any terminal on Linux, Windows and macOS, also over SSH. The default colours need only the 16 basic colours. No special font is needed.
  • Everything can be done from the keyboard; the mouse is optional.
