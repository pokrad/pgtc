Troubleshooting

Keys the terminal does not deliver, rendering problems, connection errors specific to pgtc, frequent questions, and the log file.

If a key does not work

pgtc sees only what the terminal emulator delivers. The affected commands have a second binding (below), are in the menu (F9 or Esc 9), and can be rebound in keymap.toml. F1 lists the keys of the focused part: a listed key that does nothing is intercepted by the terminal.

KeyProblemUse
F1 … F10Taken by the terminal (GNOME Terminal: F1, F10), lost over some SSH clients, Mac keyboards.Esc then a digit: Esc 5 = F5, Esc 0 = F10. Mac: Fn + the key.
Ctrl+TabSwitches the terminal's tabs, or arrives as Tab.F6, Alt+1 / Alt+2.
Ctrl+Shift+ZArrives as Ctrl+Z.Alt+Shift+Z.
Ctrl+SpaceSwitches the input language (macOS, Windows).Alt+/.
Ctrl+PgUp / Ctrl+PgDnGNOME Terminal, xfce Terminal: their own tabs.Alt+PgUp / Alt+PgDn.
Ctrl+Shift+Home / EndWindows Terminal scrolls its buffer.Alt+Shift+Home / Alt+Shift+End.
Shift+F3Lost in some Linux terminals.Alt+F3.
Alt+Shift + arrowsWindows Terminal moves between its panes.Drag the line above the results.
Shift+PgUp / Shift+PgDnGNOME Terminal, xterm, Konsole scroll their buffer.Shift + arrows.
Ctrl+Backspace, Ctrl+EnterArrive as plain Backspace / Enter in most terminals.Ctrl+Shift+Left then delete; Tab to OK.
Ctrl+1, Ctrl+2, Ctrl+Shift + arrowsNot reported by most terminals.Alt+1, Alt+2, Alt + arrows.
Ctrl+AGNU screen's command key.Ctrl+A A, or change screen's command key.
Every Alt keymacOS Terminal and iTerm2 type special characters.Use Option as Meta key (Terminal: Settings → Profiles → Keyboard; iTerm2: Profiles → Keys → Left Option key: Esc+).
Alt + letterOpens the terminal's window menu (Windows, Linux desktops).Turn off the terminal's menu access keys.
  • Terminals with the kitty keyboard protocol (kitty, WezTerm, foot, Ghostty, recent Alacritty, iTerm2 when enabled) deliver all of these; pgtc enables the protocol at start. The Windows console and Windows Terminal deliver most.
  • PuTTY: Alt + arrows work with the default settings; 0.77 and newer also with Terminal → Keyboard → Arrow keys with modifiers: xterm-style.

The screen looks wrong

SymptomCause and fix
Frames made of letters (q, x, l), question marks or boxesNo line-drawing characters, or the terminal is not UTF-8: set UTF-8, or turn on ASCII frames.
Gaps in frames, misaligned columnsThe font is not monospaced.
Wrong or blocky colours in Tokyo Night / DraculaNo true colour through the terminal, SSH client or screen / tmux: use a 16-colour scheme.
Garbled after a resize or a network hiccupResize the window slightly; pgtc redraws everything.
Terminal unusable after pgtc ended badlyreset.

Connecting fails

Server errors (FATAL: …) are shown verbatim with DETAIL and HINT. What is specific to pgtc:

SymptomCause and fix
A timeout after 10 secondsConnect timeout; raise it for slow links.
password authentication failed (28P01)Possibly a stale .pgpass line. The login dialog reappears; Save password replaces the line.
no pg_hba.conf entry … no encryptionOnly hostssl records match: set SSL mode require or stricter.
database … does not exist (3D000)Maintenance DB of the saved connection.
too many clients already / too many connections for role … (53300)Every pgtc tab holds a session of its own: close tabs.
A certificate error with verify-ca / verify-fullSet Root cert. file to the issuing CA's PEM file; for verify-full the Host must match the certificate.
The login dialog on every connectNo stored password for host, port, maintenance database and user, or .pgpass is ignored for its mode (chmod 600). See Passwords.
The server is refused after connectingserver_version_num below 110000; pgtc supports PostgreSQL 11 and newer.
not yet verified with pgtcA newer major version than pgtc knows; the catalog queries of the newest known version are used. A notice only.
A database cannot be expanded in the treeNo CONNECT privilege, or datallowconn = false.

Questions and answers

QuestionAnswer
New query / Open SQL file are disabledThe tree cursor is on a server, role or tablespace: these name no database. Select a database or an object in one.
F7: No developer templatesSettings → Install templates, or pgtc --setup.
F7, F4, F8 or autocomplete ask to finish or close the resultThe tab has a paused result (1,000+ rows) or a running export, so its session cannot run the catalog queries. Alt+End fetches the rest, Alt+Shift+C closes the result. See Large results.
cannot run inside a transaction block (25001)The script goes as one simple-protocol Query message, which the server runs as an implicit transaction block. Select the statement (VACUUM, CREATE DATABASE, CREATE INDEX CONCURRENTLY, …) alone and run it with Auto commit on — with it off pgtc sends BEGIN first.
A script failed in the middleNothing was changed, for the same reason — unless the script has its own COMMITs.
current transaction is aborted (25P02)Status row: Transaction aborted – ROLLBACK needed. Query → Rollback; Query → Auto rollback on error makes pgtc send it.
The tree does not show a new objectThe tree does not watch for DDL: Ctrl+R on the schema or group.
Autocomplete does not offer a new nameThe tab's name cache is dropped only after DDL executed in that tab and after a tree refresh: refresh the tree.
Copy does not reach the local clipboard over SSHIt goes through the terminal as OSC 52, which the terminal must allow (iTerm2: Applications in terminal may access clipboard; tmux: set -g set-clipboard on), with OSC 52 clipboard on in Settings. Otherwise select with the terminal: Shift + drag.
Ctrl+V pastes something old over SSHIt reads the remote host's clipboard or pgtc's internal buffer. Use the terminal's paste (Ctrl+Shift+V, Shift+Insert, right click).
Selecting text with the mouse for the terminal's own copypgtc enables mouse reporting: hold Shift while dragging.
Where is the exported file?On the host pgtc runs on (over SSH: the remote host); the export is written by pgtc, not by the server.
A SQL file is refused as not UTF-8Convert it: iconv -f WINDOWS-1250 -t UTF-8 old.sql > new.sql.
The profiler does not startlogging_collector must be on (needs a server restart). The role must be allowed to run ALTER SYSTEM, pg_reload_conf() and pg_read_binary_file(): a superuser, or pg_read_server_files plus the right to run ALTER SYSTEM — usually not available on managed services. See SQL profiler.
A question about logging settings on connectpgtc ended while the profiler ran; the server still logs every statement. Yes restores the parameters. See If pgtc could not put the settings back.
The dashboard shows - or no query text for other sessionsThe role is neither superuser nor member of pg_read_all_stats (pg_monitor).
Cancel or terminate is refused in the dashboardpg_cancel_backend() / pg_terminate_backend() on other roles' backends need pg_signal_backend; on superusers' backends, a superuser.
Altering or dropping an object from a dialogNot offered; pgtc generates DDL for review: Ctrl+E (Edit in new query tab), F7 (developer templates), F4 (generate commands).
Editing rows in the result gridThe grid is read-only; gtu table on F4 generates the UPDATE.
Moving the setup to another machinesettings.toml, keymap.toml, the themes and developer_templates folders (Files and folders), and .pgpass.
